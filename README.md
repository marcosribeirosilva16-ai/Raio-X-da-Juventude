# 🎯 Raio-X da Juventude

Projeto de diagnóstico socioeconômico e educacional para jovens de baixa renda, identificando fatores de vulnerabilidade e propor soluções de impacto social.

## 📂 Arquivos do Projeto
- 📓 [`RaioX_Juventude_Analise.ipynb`](./RaioX_Juventude_Analise.ipynb) — **Clique aqui para ver a análise completa e os gráficos**
- 📊 [`dados_juventude_processados.csv`](./dados_juventude_processados.csv) — Base de dados tratada

---

## 📊 Principais Resultados
- **Inclusão Digital:** 42% dos jovens não possuem internet rápida em casa.
- **Risco de Evasão:** 38,4% apresentam alta vulnerabilidade ou elevado estresse.
- **Infraestrutura Escolar:** Avaliação média de apenas 2,2 de 5,0 nas escolas públicas.

---

## 💡 3 Pilares Estratégicos
1. **Inclusão Digital:** Criação de polos comunitários de estudos com Wi-Fi gratuito.
2. **Apoio Socioemocional:** Mentoria estudantil e acompanhamento psicológico escolar.
3. **Ensino do Futuro:** Cursos básicos de tecnologia e análise de dados no ensino médio.
